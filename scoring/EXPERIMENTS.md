# Experiments

## tcc_al1_binding

This experiment checks whether a method can resolve a shallow multiquark bound state near a two-hadron threshold. It is sensitive to sampling quality and coupled-channel treatment because the expected binding is small.

## tbb_al1_binding

This experiment checks whether a method can recover a more compact and deeply bound heavy tetraquark. It complements the shallow charm case by testing a different mass regime.

## pcc_al1_binding

This experiment checks whether a method scales from tetraquarks to a five-body pentaquark target. The expected binding is weak, so it is a harder test of whether the larger Hilbert space is handled correctly.
