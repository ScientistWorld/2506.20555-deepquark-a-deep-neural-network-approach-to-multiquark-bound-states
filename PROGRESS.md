# Progress

## What Works

- Paper analysis is complete for the core AL1 tetraquark and pentaquark claims.
- The authors' DeepQuark code release is vendored under `method/DeepQuark`.
- `scripts/method.sh` trains/evaluates a configured DeepQuark target and copies artifacts into `checkpoints/`.
- `scripts/evaluate.sh` reads artifacts through `eval/deepquark_scores.py` and writes `scoring/scores.json` without importing `method/`.
- `python validate.py --compare` passes on baseline-only scores.

## Results

No reproduced DeepQuark result yet. `scoring/scores.json` currently contains only threshold baselines generated by the evaluator. The first submitted job is a small GPU smoke test for `ccqq`, not a convergence run.

## Remaining

- Run the smoke job and fix any environment/runtime issues.
- After `method_runs`, scale `ccqq` sample counts and iteration counts until the Tcc binding energy is below threshold.
- If core claim is reached, add `bbqq` and then `ccqqc` runs for broader coverage.

## Issues

- The upstream code requires JAX, Flax, and NetKet. The container has been updated to Python 3.12 with `jax[cuda12]==0.5.3` and `netket==3.17.*`, but this has not yet been exercised on a compute node.

## Deviations from Paper

- Initial submitted job scales down Monte Carlo chains, samples, and optimization iterations for a smoke test. The algorithm, Hamiltonian, symmetry projections, model family, and coupled-channel representation are unchanged. This smoke run cannot support a milestone above `method_runs`.
